# pagratios.github.io

This public repository is pagratios's GitHub Pages site, published at <https://pagratios.github.io/>. It hosts documents and downloads for apps maintained by pagratios. It contains no application source code, credentials, or user data.

Pages serves the `main` branch from the repository root. Binaries belong in this repository's Releases, not in git.

## ReBloom

The ReBloom privacy policy is maintained at [`rebloom/privacy/index.html`](rebloom/privacy/index.html) and published at <https://pagratios.github.io/rebloom/privacy/> via GitHub Pages. Keep the published policy in sync with the app's actual data handling and update its effective date when the policy changes. Review integrations, permissions, retention, and contact information before each material update. The policy is plain HTML and needs no build step.

This repository was called `public-docs` before, and released versions of the app link to <https://pagratios.github.io/public-docs/rebloom/privacy/>. [`public-docs/rebloom/privacy/index.html`](public-docs/rebloom/privacy/index.html) redirects that address to the new one: keep it, and never create a repository named `public-docs` with Pages on, which would take that path over.

## Beanbox for Decaid

The Beanbox plugin and skin for the Decent espresso machine are released on [pagratios/beanbox-decaid](https://github.com/pagratios/beanbox-decaid), not here: Decaid installs and updates them from that repository's latest release.
